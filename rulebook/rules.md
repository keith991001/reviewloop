# Rulebook

Reviewer agent 每轮评审都会读取本文件。每条规则来自一次人类 review 意见的沉淀——同类问题不应被人类指出第二次。

格式:`R<编号> [类别] 规则描述`

## 规则

- R001 [correctness] 金额、价格等货币值禁止用 float 运算,必须用 Decimal/整数分单位
- R002 [safety] 数据库迁移不得包含删列/删表操作与数据回填混在同一个迁移里
- R003 [style] 错误信息必须面向用户可读,不得直接暴露异常堆栈或内部标识符
- R004 [testing] 修 bug 的变更必须附带一个能复现原 bug 的回归测试
